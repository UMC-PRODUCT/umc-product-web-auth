## 📸 작업 내용

> 작업한 내용을 두괄식으로 작성해주세요

- Auth App 카카오 최종 로그인을 웹 SSO용 `POST /api/v1/auth/sso/kakao`(`idToken`)로 바꿔 `UMC_SSO_LOGIN` 쿠키가 발급되도록 했습니다.
- admin audience에서는 이메일·Google과 같이 `POST /api/v1/auth/login/kakao`로 UMC 토큰을 받은 뒤 `/api/v2/member/me` 운영진 게이트를 통과한 다음 SSO를 호출합니다.
- `apiRequest`의 `credentials: "include"`로 SSO 쿠키를 수신합니다.

## 🎞️ 주요 코드 설명

> 설명이 필요한 코드 위주로 작성해주세요

### 카카오 콜백 → (admin 게이트) → SSO

```TypeScript
const tokens = await exchangeKakaoAuthorizationCode(code)

if (shouldCheckAdminAccess(clientId)) {
  const credential = await loginByKakaoCredential({ idToken: tokens.idToken })
  const decision = await evaluateAdminAccess(credential.accessToken, clientId)
  // denied → Dialog / allowed → saveAdminGateAccessToken
}

const result = await loginBySsoKakao({ idToken: tokens.idToken })
```

- SSO는 항상 `/sso/kakao`로 쿠키를 발급합니다. admin일 때만 `/login/kakao`로 운영진 여부를 먼저 확인합니다.

### SSO Kakao 요청 body

```TypeScript
export function loginBySsoKakao(token: {
  idToken: string
  accessToken?: string
}) {
  return apiRequest<SsoSocialLogin>("/api/v1/auth/sso/kakao", {
    body: JSON.stringify({
      idToken: token.idToken,
      ...(token.accessToken ? { accessToken: token.accessToken } : {}),
    }),
    method: "POST",
  })
}
```

- Auth App은 `idToken`을 필수로 보냅니다. `apiRequest`는 이미 `credentials: "include"`라 별도 설정이 필요 없습니다.
